# loop sdk

development kit for building apps in the modern age of AI, focused on decentralization

## what does it offer?
1. business logic - write statically typed backend that automatically integrates, using the modern standards of SSE
2. authentication & authorization - oauth, web3, otp
3. ethereum sdk
4. payment and subscription manager
5. ai engineering

## user exeperience
1. setup a project using the CLI or the web app
2. configure it, add an authentication provider, setup a database etc.
3. write endpoints using typescript or Rust
4. integrate it in your Javascript frontend
